# Browser Recorder

Chrome / Edge 本地录屏与截图扩展。无需注册，录像与截图保存在当前浏览器，不上传服务器。

## 功能

- **录屏**：标签页、选定区域、屏幕或窗口、摄像头，支持倒计时、暂停和多路同时录制。
- **声音与画中画**：录制标签页或系统声音、麦克风，可叠加摄像头画面。
- **截图**：可见区域、整个页面、选定区域，支持延时截图。
- **素材库**：预览、重命名、复制图片，批量下载或删除；可恢复中断录像中已保存的部分。
- **无损修剪**：去掉片头片尾，另存为新素材或替换原录像。
- **导出格式**：视频支持 MP4 / WebM，截图支持 PNG / JPEG。

## 安装

零构建、零依赖，直接加载源码。要求 Chrome 116+ 或兼容的 Edge 版本。

1. 下载并解压源码，或运行 `git clone https://github.com/SoulZhong/browser-recorder.git`。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目目录。
4. 首次使用麦克风或摄像头时，按提示授权。

更新代码后，在扩展管理页点击「刷新」，再刷新已打开的素材库页面。

## 使用

点击扩展图标，选择「录屏」或「截图」，设置模式和输入源后开始。录制结束后可在素材库中预览、修剪和下载；也可点击弹窗右上角的「素材库」随时打开。

在素材库点击「修剪」，拖动时间轴上的入点和出点，再选择另存或替换。入点会对齐到前一个关键帧，保存前可查看实际起点。

## 注意事项

- 素材仅存于浏览器本地，重要内容请及时下载。卸载扩展会删除本地素材。
- MP4 录制需要 Chrome 130+ 和可用的 H.264 编码器，不支持时使用 WebM。
- 浏览器内置页面和扩展商店等受保护页面的部分功能受限。
- 无痕窗口的录制仍保存到常规浏览器资料中，不会随无痕窗口关闭而删除。
